# BUILD-00110 — Lookbook Output Page Preview

## Implementation

- `LookbookDraftWorkspace` now requests a signed preview URL for each attached output's exact immutable `AssetVersion` and displays the ordered page thumbnails in the output assembly panel.
- Preview uses `POST /v1/assets/{asset_id}/versions/{version_id}/preview-url`, so a later current-version change cannot silently substitute a different image in the assembly review.
- Preview URL issuance verifies the exact version file size and SHA-256 (implemented in BUILD-00107); the UI does not receive private storage paths.
- A failed preview request is not treated as a successful visual review. The assembly review endpoint independently reports `integrity_error` when an attached Photo output fails file/snapshot verification.
