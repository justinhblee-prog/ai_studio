# BUILD-00092 — Image Asset Foundation and Photo Draft Preparation

## Image assets

- Added `POST /v1/assets/images` for PNG, JPEG and WebP uploads.
- Pillow performs format detection, extension agreement, full pixel decoding, single-frame validation, byte limit enforcement, and dimension/pixel bounds. Client MIME is not trusted.
- Asset list accepts `kind=all|model|image`; the 3D Viewer requests only `kind=model`.
- Images share private storage, SHA-256 integrity audit, signed preview, immutable version history and verified restore. Version uploads cannot change an image asset into a model or vice versa.
- `Pillow>=10,<13` added to backend requirements.

## Photo Draft preparation

- Added workspace-scoped non-billable Photo Draft API: create, list, read, update, archive and event history.
- Input contract requires an active same-workspace image source; optional mask and reference image assets are validated in the same way.
- Operations: `ENHANCE`, `BACKGROUND`, `LIGHTING`, `RETOUCH`, `COMPOSE`; output format PNG/JPEG/WEBP; output count 1..10; identity/product/text preservation flags; optional target style and prompt.
- `photo_draft_events` is append-only. Active Photo Draft references protect their image assets from deletion (409); archive releases the protection without deleting draft history.
- No Generation Job, Quote, Credit reservation, Provider request, or Output is created. This is preparation only, not a completed Photo Engine.
