# BUILD-00109 — Lookbook Output Assembly Review / Approval

## Implementation

- Added `lookbook_output_assembly_review_events` with append-only SQLite UPDATE/DELETE triggers.
- Added workspace-scoped `GET /v1/lookbook-drafts/{draft_id}/outputs/review`, `POST .../outputs/submit`, `POST .../outputs/approve`, and `POST .../outputs/reject`.
- Submission is allowed for owner/admin/editor only after the Lookbook plan is approved and at least one approved Photo output is attached. Submission snapshots a canonical SHA-256 over the immutable ordered output sequence and its Product/Variant/SKU/caption metadata.
- Owner/admin can approve or reject. Rejection requires a comment and is terminal; because output items are immutable, a rejected sequence must be rebuilt in a new Lookbook draft. Viewer can read review history but cannot submit/decide/export.
- Once assembly review is submitted, output attachment is frozen. No additional Photo output can be appended after snapshot creation.
- Submit, approval and manifest export revalidate each Photo review snapshot and exact immutable AssetVersion file path/size/SHA-256. Corruption changes review read state to `integrity_error` and blocks approval/export until the underlying integrity issue is resolved.
- `POST .../outputs/manifest` now requires the latest assembly review to be approved and its snapshot hash/output count to match. Manifest sets `output_assembly_approved=true`, records reviewer/time/snapshot hash, and retains publication/commercial rights flags false.
- `LookbookDraftWorkspace` now supports assembly submit, owner/admin approval/rejection, review status and manifest export only after assembly approval.
