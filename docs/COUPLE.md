# 커플(2인) 착장 파이프라인 — 1단계 (R-ENGINE-16) — `app/couple.py`

자체 코드(Pillow만, 모델·네트워크 없음). **나란히 선 커플만** 다룬다. API·화면 연결은 아직 없다(모듈·시험까지; 화면 계약 `persons:[{side,garments}]`, `match` 처리는 미연결).

## 이미지 경로
1. **사람 분리**: 고전 배경 제거(`bg_removal.auto`)의 마스크 → 전경 무게중심 근처에서 **전경이 가장 적은 세로줄**로 좌/우 분할.
2. **겹침 기록**: 분할선 주변 띠(그림 폭의 ±4 %)에서 전경이 **끊기지 않고 이어진 행 수 × 띠 폭** = `overlap_px`. 사이가 완전히 비면 0. 작은 사람 면적 대비 비율(`overlap_share`)이 한도(**제안값 4 %**)를 넘으면 `COUPLE_OVERLAP_TOO_LARGE`로 **거부**.
3. **한 사람씩**: 사람마다 RGBA 잘라내기(다른 사람 쪽 픽셀은 투명, 경계 번짐 2 px)를 주입된 `runner(crop, side)`에 넘긴다(자체 own3d mock이나 승인된 평가 모델 — 이 모듈은 호출하지 않는다). 결과가 같은 크기여야 한다.
4. **원위치 합성**: 잘라낸 위치에 알파로 붙임(배경은 그대로).
오류: `COUPLE_OVERLAP_TOO_LARGE` · `COUPLE_PERSON_NOT_FOUND`(한쪽이 거의 비었음) · `COUPLE_RUNNER_SIZE`(모두 `error_catalog`에 ko/en 문구).

## 3D 경로
`scene_two(성별 좌·우, 옷 종류 좌·우, 치수 좌·우)` — 마네킹 2개를 0.62 m 간격으로 세우고 사람마다 자기 `garment.v1` 샘플 옷을 맞춘다(`render3d_scene.build_layers`). 기존 `render3d_soft`로 어느 각도에서든 그린다. `render_check`(`render_qc`)를 사람별로 돌리는 것은 아직 연결하지 않았다(미실행).

## 시험 (합성, 7개)
두 사각 인물 그림: 겹침 없음 / 손이 건너는 작은 접촉(6행) → 기록·수락 / 큰 접촉(60행)·몸이 합쳐짐 → 거부 / 한쪽만 있음 → 사람 없음 / 사람별 처리와 원위치 / 결정성 / 3D 2인 장면 5각도.

## 한계 (정직하게)
- **실제 커플 사진으로는 시험하지 않았다**(합성 사각 인물만; 미실행). 분할선은 **직선**이라 팔짱·손잡기가 크면 거부되고 사람 한 명이 다른 사람 뒤에 반쯤 가려진 경우, 키 차이가 큰 경우, 아이를 안은 경우는 처리하지 못한다.
- 겹침 한도 4 %와 띠 폭은 **제안값**(실사진 미조정). 배경 제거가 어려운 배경(복잡한 무늬)에서는 분할이 틀릴 수 있다.
- 두 사람 사이의 자연스러운 경계 블렌딩은 알파 번짐 2 px뿐이다(그림자·반사 일치 없음). `match:'same'|'color'`(같은/맞춘 색 옷)은 서버에서 아직 다루지 않는다.
