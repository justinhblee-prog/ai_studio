# BUILD-00113 — OpenAPI Runtime Contract Reconciliation

## Scope

- Establish a version-controlled OpenAPI snapshot generated from the actual FastAPI runtime.
- Add a deterministic exporter with `--check` mode so unreviewed API contract changes fail tests/verification.
- Record operation-level reconciliation decisions without changing existing runtime behavior or silently rewriting the product design draft.
- Preserve the three unimplemented credit/quote operations as deferred pending approved billing and credit policy.

## Changes

- Added `docs/api/openapi.runtime.v1.json` (80 runtime path items).
- Added `scripts/export_runtime_openapi.py` and snapshot regression tests.
- Added `docs/api/OPENAPI_CONTRACT_RECONCILIATION_BUILD-00113.md` describing authority, compatibility rules, drift, and deferred decisions.
- Added current runtime/design comparison outputs under `docs/reports/`.

## Audit

- Design: 13 path items / 15 operations.
- Runtime: 80 path items.
- Matched design operations with structural drift: 12.
- Design operations absent from runtime: 3 (`GET /credits/accounts/{account_id}`, `GET /credits/accounts/{account_id}/ledger`, `POST /quotes`).
- The audit is structural only; it does not establish semantic equivalence or live payload conformance.

## Compatibility decisions

- No runtime endpoint, request/response body, status code, pagination, or auth behavior changed.
- Generated FastAPI operation IDs remain unchanged pending generated SDK compatibility policy.
- `limit` + `offset`, optional `Idempotency-Key`, and optional cancel body remain the current runtime contract.
- Credit/quote endpoints remain deferred; no placeholder API or credit policy was invented.

## Verification

- Full backend suite: 347 tests reported passed (345 baseline + 2 new snapshot tests); the runner did not terminate cleanly after reporting completion, so a clean full-suite process exit was not established.
- Focused OpenAPI tests: 4 passed.
- `python -m compileall -q app scripts tests`: passed.
- Runtime OpenAPI snapshot `--check`: passed.
- Structural audit: 15 compared, 12 drifted, 3 unmatched.
- Browser/TypeScript/WebGL/Android and production integration: not verified.
