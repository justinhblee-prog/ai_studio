# 의류 메시 변형 맞춤 (R-ENGINE-03b · 트랙 A 1단계)

`app/garment_deform.py` — `garment.v1` 의류(GLB + 사이즈표, `app/garments.py`)를 **기본 인체(`app/base_models.py`)에 몸 치수를 넣어 맞춘다**(방식 이름 `profile-ratio.v1`). 순수 파이썬·CPU만, 같은 입력 = 같은 바이트.

## 방식
의류는 기준 몸(프리셋)을 감싸도록 만들어져 있고, 각 정점을 **같은 높이에서의 목표 몸 단면 ÷ 기준 몸 단면 비율**로 옮긴다(몸통은 가로·세로 단면, 다리는 중심선+반지름). 여유(몸과 의류 사이 간격)도 같은 비율로 늘어나므로, **몸 안으로 파고드는 정점이 있으면 결과를 거부**한다(성공 반환의 `penetrations`는 항상 0).

## 다른 세션의 R-ENGINE-03a(`app/garment_fit.py`)와의 관계 — 겹치는 부분 있음
03a는 **레인 2 치수 마네킹 위에 사이즈표 둘레로 상의 껍데기**를 얹는 다른 설계이고 이미 main에 있다. 03b는 **garment.v1 규격 의류(상·하의)를 base_models 인체에 맞추는** 방식이다. **두 갈래가 한 목적(치수에 맞춘 옷)으로 겹치므로 하나로 합칠지는 설계 결정(NEED_USER)** — 이번 PR은 이름만 달리해 둘 다 남겼다.

## 안 되는 것
천 시뮬레이션 아님(주름·늘어짐·자세 없음), 소매·목·실제 의류 모양 없음, 팔과의 충돌 검사 없음, 사용자 옷 사진·실사 보정(트랙 B)은 이후 단계. 결과는 "참고용(근사치)" 성격이다.

## 의류 종류 확대 (R-ENGINE-09)
`garments.KINDS = top · bottom · skirt · dress · jacket`. **바지는 기존 `bottom`**(다리 두 개가 있는 바지 튜브)이다. 새 부위: `skirt`(허리→무릎 위, 허리·엉덩이·두 허벅지를 감싸는 **외피 타원**을 기준으로 변형 — `garments.skirt_stops`), `arm_l`/`arm_r`(재킷 소매, 팔 중심선·반지름 — `garments.arm_stops`). 원피스 = 몸통(어깨→허리) + 치마(허리→밑단)가 허리 고리에서 **같은 점**으로 이어진다(시험으로 고정). 재킷 = 여유 +6 cm(겉옷)인 몸통 + 소매 두 개, 치수표에 `sleeve_cm` 필수.
시험: `tests/test_garment_kinds.py`(종류별 유효성·사이즈표 증가, 작은/중간/큰 몸 3종 맞춤 관통 0, 치마와 다리 간격 격자, 원피스 허리 이음새, 재킷 소매, own3d mock 수락).
**한계(정직)**: 의류 기준 몸은 여전히 R-ENGINE-02/03의 단순 단면(`PRESETS`)이다. R-ENGINE-08에서 몸 메시가 곡선(가슴 앞쪽·겨드랑이·허벅지)을 얻어, **그 몸 위에 겹쳐 그리면 가슴·겨드랑이·허벅지 일부가 옷 밖으로 비친다**(미리보기로 확인). 단면 기준 관통 시험은 통과하지만 새 몸 메시 기준은 아님 → 후속(의류 기준 단면을 몸 메시와 맞추기).
