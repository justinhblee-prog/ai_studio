# BUILD-00093 — Lookbook Draft Preparation

## Implementation

- Added workspace-scoped `LookbookDraftInput` and persistence for non-billable campaign composition drafts.
- Product image assets (1..20) are required; optional person image must also be a unique active same-workspace image Asset.
- Optional Project must be ACTIVE and belong to the Workspace. Optional Character must be active and belong to the same Workspace.
- Added create/list/read/update/archive/event-history APIs. Create/update/archive events are append-only.
- Active drafts protect referenced image Assets, Projects and Characters from deletion/archive transitions. These checks and writes use SQLite `BEGIN IMMEDIATE` to serialize with draft creation/update/archive. Archive releases active reference protection while preserving the draft/event record.
- Added `LookbookDraftWorkspace` React UI and package exports. It loads image, project, character and draft lists; creates and archives drafts.

## Explicit exclusions

- SKU/catalog management and product-variant uniqueness are not implemented.
- No Generation Job, Quote, Credit reservation, Provider call, generated Output, review/approval, or export is created.
- The UI supports selecting multiple product images; SKU/catalog and variant uniqueness remain absent.
- This is Lookbook preparation only, not a completed Lookbook production workflow.
