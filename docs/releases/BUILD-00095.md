# BUILD-00095 — AssetRelation Graph Integrity

## Implementation

- `derived_from` relations now reject a cycle before insert. A recursive CTE walks existing directed `derived_from` edges from the proposed target and rejects the edge if it can reach the proposed source.
- Relation create executes under SQLite `BEGIN IMMEDIATE`, serializing concurrent edge insertions so simultaneous requests cannot both pass a stale cycle check.
- Relation creation now appends provenance to both endpoints: `asset.relation_created` on the source and `asset.relation_received` on the target.
- Other relation types and relation deletion/retention semantics are unchanged; no existing relation is deleted or rewritten.
