# AI CREATOR STUDIO

## 통합 AI 캐릭터·포토리얼 룩북 플랫폼 사업 기획서

-   문서 버전: v1.0
-   작성 기준: 2026-10-31
-   문서 목적: 서비스 비전, 사업 구조, 메뉴 체계, 핵심 기능, 수익 모델,
    개발 우선순위의 기준 문서
-   제품 가칭: **AI CREATOR STUDIO**
-   핵심 슬로건: **캐릭터는 3D로 설계하고, 결과물은 실제 사진처럼.**

# 1. 사업 개요

## 1.1 서비스 정의

AI CREATOR STUDIO는 사용자가 자신만의 AI 인물·커플·브랜드 모델을 만들고,
이를 일관된 외형으로 유지하면서 사진형 이미지와 패션 룩북 콘텐츠를
제작하는 통합 창작 플랫폼이다.

일반적인 이미지 생성 서비스처럼 매번 프롬프트를 새로 입력하는 방식에서
벗어나, 캐릭터의 얼굴·체형·헤어·피부·의상 취향 등을 구조화된 데이터로
관리한다. 생성한 캐릭터는 다양한 의상, 포즈, 표정, 카메라 구도, 배경에
반복 활용할 수 있다.

서비스의 차별화 기능으로 **3D 캐릭터 설계와 포토리얼 2D 이미지 출력의
하이브리드 기술**을 포함한다. 사용자는 3D 캐릭터를 회전·수정하며 외형을
설계하지만, 최종 결과물은 CGI 렌더처럼 보이는 이미지가 아니라 실제
카메라로 촬영한 인물 사진에 가까운 JPG/PNG가 되도록 한다.

## 1.2 비전

-   개인 창작자에게는 자신만의 AI 캐릭터 제작·활용 공간을 제공한다.
-   쇼핑몰과 패션 브랜드에는 전속 가상 모델과 룩북 제작 도구를 제공한다.
-   콘텐츠 제작자에게는 이미지·영상·광고 소재를 반복 생산하는 제작
    환경을 제공한다.
-   장기적으로 캐릭터와 스타일 프리셋을 공유·판매하는 크리에이터
    생태계를 구축한다.

# 2. 목표 고객 및 시장 포지션

## 2.1 주요 고객군

### A. 개인 창작자

-   AI 캐릭터와 가상 인물을 만들고 싶은 사용자
-   SNS 프로필, 세계관, 웹소설·게임 콘셉트용 캐릭터가 필요한 사용자
-   다양한 스타일의 인물 이미지를 꾸준히 제작하는 사용자

### B. 패션 쇼핑몰·브랜드

-   의류 상세페이지와 시즌 룩북을 제작하는 온라인 셀러
-   고정된 브랜드 모델을 유지하고 싶은 패션 브랜드
-   신상품 출시 때마다 촬영 비용과 일정 부담이 큰 소규모 사업자

### C. 마케팅·콘텐츠 제작자

-   광고 이미지와 SNS 콘텐츠를 빠르게 제작해야 하는 마케터
-   가상 인플루언서와 UGC형 콘텐츠를 제작하는 크리에이터
-   여러 인물·의상·배경 조합을 대량 제작하는 제작사

## 2.2 초기 시장 진입 전략

초기에는 기능을 모두 완성하려 하기보다, **캐릭터 제작 + 얼굴 일관성 +
포토리얼 이미지 생성 + 의상 가상 착용**을 중심으로 유료 고객을 확보한다.

권장 초기 공략 순서: 1. AI 이미지 제작에 익숙한 개인 창작자 2. 소규모
패션 쇼핑몰 및 온라인 셀러 3. 콘텐츠 마케팅 대행사와 브랜드 운영팀 4.
캐릭터·프리셋 마켓플레이스 크리에이터

# 5. 핵심 기능 상세

## 5.1 Character Studio --- 캐릭터 제작

### 기본 정보

-   캐릭터 이름 및 설명
-   성별 표현 및 연령대 설정
-   단독 인물 또는 커플 구성
-   캐릭터 콘셉트와 스타일
-   기본 의상 및 대표 포즈

### 외형 세부 설정

-   얼굴형
-   눈 모양 및 눈매
-   눈썹 모양
-   코 모양
-   입술 모양
-   피부톤과 피부 질감
-   헤어 스타일·컬러·텍스처
-   체형과 신체 비율
-   액세서리

### Character DNA

캐릭터의 외형과 정체성을 구조화해 저장하는 핵심 데이터다.

포함 항목: - 얼굴 정체성 참조 이미지 - 얼굴 특징 설명 및 파라미터 -
헤어·피부·체형 설정 - 기본 스타일과 의상 취향 - 허용 가능한 변형 범위 -
캐릭터 버전과 변경 이력

목표는 장면과 의상이 바뀌어도 동일 인물로 인식되는 결과를 만드는 것이다.

## 5.2 Face Lock --- 얼굴 일관성

-   기준 얼굴 이미지와 캐릭터 DNA를 연결한다.
-   생성 과정에서 얼굴 정체성을 우선 유지한다.
-   표정·조명·각도 변화는 허용하되 인물 자체가 바뀌지 않도록 제어한다.
-   캐릭터별 기준 이미지와 생성 성공 사례를 보관한다.
-   얼굴 유사도와 결과 품질을 검수하는 내부 평가 기능을 둔다.

## 5.3 3D Character Lab --- 3D 설계와 포토리얼 2D 출력

### 제품 목표

**사용자는 3D로 캐릭터를 설계하고 확인하지만, 최종 다운로드 결과는 실제
카메라로 촬영한 듯한 사진형 2D 이미지여야 한다.**

3D 캐릭터 자체를 게임 캐릭터나 플라스틱 인형처럼 보여주는 것을 최종
목표로 삼지 않는다.

### 권장 기술 파이프라인

``` text
기준 인물 이미지 / Character DNA
              ↓
       3D 인체·얼굴 복원
              ↓
     3D 모델·재질·리깅 구성
              ↓
     카메라·포즈·조명 설정
              ↓
    3D 렌더 패스 생성
 (색상 / 깊이 / 노멀 / 마스크)
              ↓
    AI 뉴럴 렌더링·사진 보정
              ↓
     얼굴·의상 일관성 검수
              ↓
       포토리얼 2D 출력
```

### 핵심 구성 기술

1.  **3D 복원**
    -   기준 이미지에서 얼굴과 신체의 3D 구조를 추정한다.
    -   단일 이미지에서 보이지 않는 뒷면과 측면은 추정 정보임을 전제로
        한다.
    -   가능하면 정면·측면·후면 등 복수 참조 이미지를 활용한다.
2.  **물리 기반 렌더링(PBR)**
    -   피부의 반투명 효과(Subsurface Scattering)
    -   머리카락의 가닥과 광택
    -   섬유·가죽·니트 등 의상 재질
    -   실제 환경에 가까운 조명과 그림자
    -   카메라 렌즈와 심도 표현
3.  **AI 뉴럴 렌더링**
    -   3D 렌더 결과를 조건 이미지로 사용해 사진 질감을 강화한다.
    -   깊이·노멀·포즈·마스크 정보를 활용해 구조를 유지한다.
    -   기준 얼굴 참조와 캐릭터 정체성 조건을 함께 사용한다.
    -   과도한 이미지 변형으로 얼굴·의상·로고가 바뀌지 않도록 낮은 변형
        강도와 검수 단계를 둔다.
4.  **사진형 출력**
    -   JPG/PNG 고화질 출력
    -   인물 사진·패션 화보·쇼핑몰 상품 이미지에 맞는 프리셋
    -   선택 시점별 고품질 렌더링
    -   업스케일 및 후처리

## 6.3 크레딧 과금 원칙

생성 작업별 GPU 원가 차이가 크므로 작업 종류와 품질 등급에 따라 크레딧을
차등 차감한다.

예시 과금 단위: - 표준 이미지 생성: 기본 크레딧 - 고해상도 포토 렌더:
추가 크레딧 - 3D 모델 생성: 작업 복잡도에 따른 크레딧 - 다중 시점 이미지
팩: 시점 수에 따른 차감 - 영상 생성: 길이·해상도·모델에 따른 차감 - 일괄
룩북: 이미지 수에 따른 차감

무제한 요금제는 원가가 통제되지 않을 수 있으므로 초기에는 사용량 상한
또는 공정 사용 정책을 둔다.

   ↓

   ↓
사용자에게 완료 알림

실패·취소·시간 초과 시 크레딧 복구 규칙을 명확하게 정의한다.

    조정할 수 있게 한다.
5.  **3D는 수단, 사진은 결과:** 3D 기술 자체를 전면에 내세우기보다 실제
    사진 같은 출력 품질을 제품의 핵심 가치로 삼는다.
6.  **작업 재사용:** 캐릭터·의상·촬영 설정을 저장해 반복 제작 시간을
    줄인다.
7.  **투명한 과금:** 생성 전에 예상 크레딧을 보여주고 실패 시 처리
    규칙을 명확히 한다.

# AI CREATOR STUDIO 사업 방향 개정안 v1.1
- 개정일: 2026-10-31
- 적용 범위: 사업 포지셔닝, 첫 화면, 사용자 진입 흐름, 메뉴 IA, MVP 우선순위
- 원칙: 본 개정안은 v1.0의 해당 항목보다 우선 적용한다. 기존 기술 방향(Character DNA, Face Lock, 3D 설계와 포토리얼 2D 출력)은 유지한다.

## A. 사업 포지셔닝 변경

### A.1 핵심 정의
AI CREATOR STUDIO는 **기업의 기존 이미지 자산을 편집·확장하고, 브랜드 일관성을 유지하며, 상품·모델·마케팅 이미지를 대량 제작하는 B2B 중심 AI 비주얼 콘텐츠 제작 플랫폼**이다. 개인 사용자는 일부 기능을 셀프서비스 방식으로 이용하는 보조 고객군으로 둔다.

캐릭터 생성은 플랫폼의 중요한 차별화 기능이지만, 모든 사용자가 캐릭터를 먼저 만들어야 하는 진입 조건은 아니다.

### A.2 고객 우선순위
1. **핵심 B2B:** 패션·의류 쇼핑몰, D2C 브랜드, 유통·이커머스 사업자
2. **확장 B2B:** 광고·마케팅 대행사, 콘텐츠 제작사, 브랜드 인하우스 팀, 리셀·마켓플레이스 운영사
3. **보조 B2C:** 개인 사진 편집, AI 인물·캐릭터 제작, SNS 콘텐츠 제작 사용자

### A.3 고객이 시작하는 5가지 작업
| 진입 작업 | 입력 | 주요 작업 | 결과 |
|---|---|---|---|
| 기존 사진 편집 | 인물·모델·브랜드 사진 | 배경·의상·헤어·조명·구도·분위기 변경, 불필요 요소 제거 | 수정된 사진, 캠페인 변형 컷 |
| 상품 이미지 제작 | 제품 단독 사진·플랫레이·마네킹 컷 | 배경·연출 변경, 제품 상세 이미지, 채널별 규격화 | 상품컷, 라이프스타일 컷 |
| 가상 모델·착용 컷 | 의상 이미지 + AI 모델 또는 브랜드 모델 | 모델 선택, 가상 착용, 포즈·배경 변경 | 모델 착용 컷, 룩북 |
| 브랜드 모델 제작 | 기준 인물 이미지 또는 외형 설정 | AI 모델 생성, Character DNA, Face Lock | 반복 활용 가능한 브랜드 전속 모델 |
| 신규 AI 이미지 생성 | 텍스트·참조 이미지·프리셋 | 인물·장면·콘셉트 생성 | 신규 광고·SNS·콘셉트 이미지 |

### A.4 기존 사진 편집을 독립적인 핵심 기능으로
사용자가 단순히 자기 사진이나 보유한 모델 사진을 업로드하고 원하는 부분만 바꾸려는 경우를 별도 진입 흐름으로 지원한다. 이 작업은 캐릭터 생성이나 룩북 제작으로 강제 연결하지 않는다.

편집 시작 시 다음 작업을 명확하게 구분한다.
- 배경 변경 및 배경 확장
- 의상 변경 또는 색상 변경
- 헤어·메이크업·액세서리 변경
- 조명·색감·사진 분위기 변경
- 구도·화면비·이미지 크기 변경
- 인물·제품·사물의 일부 수정 또는 제거
- 원본 인물의 정체성 및 제품 디자인 보존

업로드 전에는 사용 권한 확인, 인물 사진의 동의·권리, 민감 이미지 처리, 보관·삭제 정책을 안내한다. 편집 시에는 원본 보존과 버전 비교·되돌리기를 기본으로 제공한다.

## B. B2B 중심 홈페이지 개편

### B.1 첫 화면의 역할
첫 화면은 기능 카탈로그가 아니라 **기업 고객의 업무 문제를 해결하는 진입 포털**이다. 방문자는 자신의 작업을 선택하고, 샘플을 확인하고, 파일을 올리거나 상담을 요청할 수 있어야 한다.

### B.2 권장 홈페이지 구조
1. **상단 내비게이션:** 솔루션 / 작업 시작 / 활용 사례 / 요금·도입 / 로그인
2. **히어로 메시지:** “기존 사진부터 브랜드 룩북까지, AI로 더 빠르게”
3. **주요 CTA:** 이미지 편집 시작 / 상품 이미지 제작 / 브랜드 상담
4. **업무별 진입 카드:** 기존 사진 편집 / 상품 이미지 / AI 모델·가상 착용 / 룩북·캠페인
5. **B2B 신뢰 영역:** 활용 사례, 작업 전후 비교, 처리 규모·품질 관리 방식, 고객사 로고(실제 확보 후)
6. **워크플로 설명:** 업로드 → 편집 방향 선택 → 브랜드 기준 적용 → 검수 → 일괄 출력
7. **기업 도입 영역:** 팀 협업, 브랜드 키트, 일괄 처리, API·스토어 연동 문의
8. **B2C 보조 영역:** 개인 사진 편집과 AI 캐릭터 만들기

### B.3 로그인 전·후 화면
- 비회원: 솔루션과 사례를 먼저 보여주고, 샘플 탐색과 데모 요청을 허용한다. 실제 생성 또는 저장 시 가입을 유도한다.
- B2B 회원: 최근 프로젝트, 브랜드 키트, 팀 작업, 대량 업로드, 검수 대기, 사용량을 우선 표시한다.
- B2C 회원: 최근 편집, 내 캐릭터, 개인 생성 작업과 크레딧을 우선 표시한다.

## C. 메뉴 IA 개정

### C.1 상단 메뉴(방문자 기준)
- **솔루션:** 사진 편집, 상품 이미지, AI 모델·가상 착용, 룩북·마케팅, 기업용 대량 제작
- **작업 시작:** 사진 편집하기, 상품 이미지 만들기, AI 모델 만들기, 룩북 만들기
- **활용 사례:** 패션·뷰티·리빙·식품 등 업종별 사례, 전후 비교, 템플릿
- **요금·도입:** 셀프서비스 요금제, 기업 플랜, 상담·데모 신청
- **로그인 / 무료로 시작하기**

### C.2 로그인 후 작업 공간
- **워크스페이스 홈:** 최근 프로젝트, 팀 현황, 사용량, 빠른 작업 시작
- **이미지 편집:** 원본 업로드, 부분 편집, 배경·의상·헤어·조명 변경, 버전 비교
- **상품 콘텐츠:** 상품 이미지, AI 제품 연출, 가상 착용, 상세페이지 컷
- **브랜드 모델:** AI 모델 생성·보관, Character DNA, Face Lock
- **룩북·캠페인:** 시즌 룩북, 광고·SNS 소재, 일괄 생성
- **에셋·브랜드 라이브러리:** 원본·결과물, 브랜드 컬러·로고·폰트·템플릿, 모델·프리셋
- **팀·관리:** 멤버·권한, 승인·검수, 사용량·크레딧, 결제, API 연동(기업 플랜)

### C.3 기능 배치 원칙
- Character Catalog는 독립적인 주 메뉴보다 브랜드 모델 생성·편집 과정 안의 외형 옵션 라이브러리로 제공한다.

- Creator Market은 초기 B2B 핵심 흐름에서 제외하고, 장기 확장 기능으로 둔다.
- Content Studio는 독립 도구보다 룩북·캠페인 작업에서 결과물을 확장하는 기능으로 우선 제공한다.

# AI CREATOR STUDIO 플랫폼 통합 방향 및 작업 인수인계 v1.2
- 작성일: 2026-10-31
- 목적: 다른 대화·작업 환경에서도 프로젝트를 이어갈 수 있도록 현재 합의사항과 다음 작업을 기록
- 기준 문서: v1.0 사업 기획서 및 v1.1 B2B 개정안에 이어지는 추가 개정

## 1. 현재 확정된 사업 방향

### 1.1 플랫폼 정체성
AI CREATOR STUDIO는 **B2B를 기본으로 하는 AI 비주얼 콘텐츠 제작 플랫폼**이다. 기업과 브랜드가 보유한 사진·상품 이미지·브랜드 자료를 업로드하고, 플랫폼이 제공하는 기본 자산과 결합해 원하는 이미지·룩북·마케팅 콘텐츠를 제작한다.

B2C는 개인 사진 편집, AI 캐릭터 제작, 개인 이미지 생성 등을 제공하는 보조 고객군으로 운영한다.

### 1.2 핵심 원칙
1. 고객이 반드시 AI 캐릭터를 먼저 만들 필요는 없다.
2. 고객은 기존 사진 한 장만 업로드해도 편집을 시작할 수 있어야 한다.
3. 플랫폼은 다양한 기본 자산과 템플릿을 제공해 준비물이 없는 고객도 시작할 수 있게 한다.
4. 고객의 자체 자료와 플랫폼 기본 자산을 자유롭게 조합할 수 있어야 한다.
5. 고객은 작업 결과를 저장·수정·비교·재사용할 수 있어야 한다.
6. 사용자가 만든 자산을 직접 공개·등록해 다른 사용자에게 판매할 수 있는 마켓플레이스를 장기 구축한다.
7. 개인 작업물과 비공개 기업 자료는 명시적 공개·판매 동의 없이 마켓에 노출하지 않는다.

## 2. 제작 시작 방식: 기본 자산 + 고객 자체 자료

### 2.1 플랫폼 기본 제공 자산
- 인물: 남성·여성·커플 AI 모델
- 얼굴: 얼굴형, 눈, 눈썹, 코, 입술, 피부톤·피부 질감
- 헤어: 스타일, 색상, 질감
- 의상: 캐주얼, 정장, 스포츠, 계절별, 파티 등
- 포즈: 인물, 커플, 제품 촬영 포즈
- 배경: 스튜디오, 실내, 야외, 상업 공간
- 촬영: 카메라, 렌즈, 조명, 구도
- 템플릿: 광고, 상품 상세페이지, SNS, 룩북
- 프롬프트·스타일 프리셋 및 후속 확장 자산

기본 자산은 무료/유료, 개인용/상업용 라이선스를 구분해 관리한다. 라이선스와 상업적 이용 가능 여부는 자산 상세 페이지에서 구매 전에 명확히 표시한다.

### 2.2 고객이 업로드할 수 있는 자료
- 개인 사진 및 인물·모델 사진
- 제품 단독 사진, 플랫레이, 마네킹 사진
- 의상·액세서리 사진
- 브랜드 로고, 컬러, 폰트, 가이드라인
- 기존 광고·룩북·캠페인 이미지
- 여러 장의 원본 이미지 및 프로젝트 자료

### 2.3 주요 제작 진입 경로
| 시작 경로 | 사용자가 제공하는 자료 | 주요 작업 | 대표 결과 |
|---|---|---|---|
| 기존 사진 편집 | 개인·모델 사진 | 배경, 의상, 헤어, 조명, 구도, 부분 수정 | 수정 사진, 변형 컷 |
| 상품 이미지 제작 | 상품 사진 | 배경·연출 변경, 상품컷 구성, 규격화 | 상품컷, 상세페이지 |
| 가상 착용 | 의상 이미지 + 모델 선택 | AI 모델 착용, 포즈·배경 변경 | 착용 컷, 룩북 |
| 브랜드 모델 제작 | 기준 인물 이미지 또는 외형 설정 | Character DNA, Face Lock, 모델 저장 | 반복 활용 브랜드 모델 |
| 신규 이미지 생성 | 텍스트·참조 이미지·프리셋 | 인물·장면·콘셉트 생성 | 광고·SNS·콘셉트 이미지 |
| 룩북·캠페인 | 상품·모델·브랜드 자료 | 다수 상품·컷 구성, 일괄 제작 | 시즌 룩북, 캠페인 |

기존 사진 편집은 독립된 핵심 작업이다. 캐릭터 생성이나 룩북으로 강제로 이동시키지 않는다.

## 3. 마켓플레이스 방향

### 3.1 목적
플랫폼 기본 제공 자산뿐 아니라 사용자가 직접 제작한 디지털 자산을 등록·판매·구매할 수 있도록 한다. 이를 통해 고객은 제작자, 판매자, 구매자 역할을 모두 할 수 있다.

### 3.2 거래 대상 자산
- AI 캐릭터 및 가상 모델
- 얼굴·헤어 프리셋
- 의상·코디 세트
- 포즈 팩
- 배경·스튜디오 세트
- 광고·룩북·SNS 템플릿
- 프롬프트 및 스타일 프리셋
- 3D 캐릭터·의상·소재 자산
- 기타 재사용 가능한 디지털 제작 에셋

### 3.3 마켓 사용자 흐름
1. 판매자가 자산을 제작하거나 보유 자산을 선택한다.
2. 판매 등록을 신청하고 미리보기·설명·가격·라이선스 범위를 설정한다.
3. 권리 확인 및 콘텐츠 검수 절차를 거친다.
4. 승인된 상품이 마켓에 공개된다.
5. 구매자는 상품 상세에서 미리보기, 라이선스, 호환 기능, 가격을 확인한다.
6. 구매 후 자신의 작업 공간 또는 에셋 라이브러리에 추가해 사용한다.
7. 판매 내역·정산·환불·분쟁 상태를 판매자 대시보드에서 확인한다.

### 3.4 마켓과 에셋 라이브러리의 구분
- **에셋 라이브러리:** 내가 보유하거나 업로드한 원본, 결과물, 구매 자산, 브랜드 자료를 저장·관리하는 개인/팀 공간
- **마켓플레이스:** 공개 판매가 승인된 자산을 검색·구매·판매하는 거래 공간

라이브러리의 비공개 자료는 판매자가 별도로 공개·판매를 신청하지 않는 한 마켓에 노출하지 않는다.

### 3.5 마켓 운영 정책의 필수 항목
- 업로드·판매자의 저작권 및 판매 권한 확인
- 인물 사진·초상권·상표·브랜드 자산의 권리 확인
- AI 생성물 및 원본 자료의 라이선스 범위 명시
- 개인용/상업용/확장 라이선스 구분
- 재판매·재배포·독점 여부 표시
- 신고·삭제·이의제기·분쟁 처리
- 환불·취소·정산 기준
- 판매자 본인 확인 및 세금·정산 관련 정책
- 유해·불법·권리 침해 콘텐츠 심사
- 구매 자산의 업데이트·호환성·버전 관리

구체적인 수수료율, 판매자 정산 비율, 독점 판매 조건은 아직 확정하지 않는다.

## 1. 핵심 전략 결정

AI CREATOR STUDIO는 패션 전용 제작 도구로 한정하지 않는다. 여러 산업에서 공통으로 사용하는 **AI 비주얼 제작 기반 플랫폼(Core Platform)**을 먼저 구축하고, 산업별 기능은 독립적인 사업 모듈(Vertical Modules)로 추가한다.

- B2B가 기본 고객 및 제품 전략이다.
- B2C는 개인 사진 편집·AI 캐릭터·개인 이미지 생성 중심의 보조 채널이다.
- 고객은 플랫폼 기본 에셋을 사용하거나 자신의 사진·상품 이미지·브랜드 자료를 업로드해 제작한다.
- 사용자가 만든 캐릭터·프리셋·템플릿 등의 자산을 거래하는 마켓플레이스를 장기 구축한다.
- 핵심 모듈은 특정 업종이나 특정 AI 모델 공급사에 종속되지 않게 설계한다.

### 2.1 모듈 경계 원칙
- 각 모듈은 명확한 책임과 데이터 소유권을 가진다.
- 다른 모듈의 내부 테이블이나 구현에 직접 의존하지 않고 API 또는 이벤트를 통해 협력한다.
- 초기에는 모듈형 모놀리스로 구현해도 되지만, 경계와 인터페이스는 분리한다.
- 실제 부하·팀 규모·배포 요구가 생긴 모듈부터 별도 서비스로 분리한다.
- 처음부터 모든 것을 마이크로서비스로 나누어 개발·운영 복잡도를 높이지 않는다.

## 5. 반드시 지켜야 할 기술 설계 원칙

### 5.1 AI 공급자 교체 가능성
- 모델 공급자별 호출 코드를 제품 업무 로직에 직접 넣지 않는다.
- 내부 표준 요청·응답 스키마를 정의한다.
- 공급자별 어댑터를 두고 모델별 기능·가격·품질·속도 정보를 관리한다.
- 공급자 장애 시 대체 모델이나 대체 워크플로를 선택할 수 있게 한다.
- 모델을 바꿔도 사용자 화면과 외부 API 계약이 불필요하게 바뀌지 않게 한다.

### 5.2 워크플로 재사용
- 업로드 → 검증 → 생성/편집 → 후처리 → 검수 → 출력 단계를 재사용 가능한 노드 또는 단계로 구성한다.
- 워크플로는 버전 관리하고 입력·출력 형식을 명확히 한다.
- 실패 단계 재시도, 작업 취소, 진행 상태, 비용 기록, 결과 추적을 지원한다.
- 단일 이미지 편집과 수천 장의 배치 작업이 동일한 엔진을 활용하되 실행 정책과 큐 우선순위는 다르게 설정한다.

### 5.3 기업별 데이터 격리
- 모든 기업 데이터에 조직/테넌트 컨텍스트를 적용한다.
- 조직별 원본·결과물·브랜드 키트·캐릭터·프로젝트·권한을 격리한다.
- 역할 기반 권한, 다운로드 권한, 외부 공유 권한을 관리한다.
- 기업별 감사 기록과 사용량·비용 집계를 제공한다.
- 상위 기업 고객의 전용 저장소·키·리전 등은 필요할 때 확장할 수 있게 한다.

### 5.4 API 우선
- 주요 기능을 내부 서비스 API로 정의한다.
- 웹 UI는 API를 사용하는 하나의 클라이언트로 취급한다.
- 추후 외부 쇼핑몰, PIM/DAM, 광고 시스템, 파트너 플랫폼과 연동할 수 있게 한다.
- 공개 API에는 인증, 권한, 속도 제한, 사용량 한도, 버전 관리, 감사 로그를 적용한다.

### 5.5 자산 권리와 출처
- 원본 업로드, 생성 결과, 플랫폼 제공 프리셋, 구매 자산을 구분한다.
- 소유자, 출처, 사용 권한, 상업적 이용 범위, 라이선스, 공개 상태를 추적한다.
- 고객의 비공개 원본과 기업 자료는 동의 없이 학습·공개·마켓 등록에 사용하지 않는다.
- 마켓 판매 등록은 명시적 신청과 권리 확인 절차를 거친다.

## 8. 성공 기준

핵심 모듈이 잘 설계되었는지는 기능 수가 아니라 재사용성으로 판단한다.

- 신규 AI 모델 공급자를 추가할 때 기존 제품 업무 로직을 크게 수정하지 않는다.
- 새 산업 모듈을 추가할 때 공통 업로드·생성·저장·과금·권한 시스템을 재사용한다.
- 하나의 워크플로를 UI, 배치 작업, API에서 재사용할 수 있다.
- 기업 간 데이터가 섞이지 않는다.
- 원본과 결과물의 출처·권리·버전을 추적할 수 있다.
- 마켓 구매 자산이 구매자의 라이브러리와 제작 워크플로에 연결된다.
- B2B 고객별 설정이 코드 분기 난립이 아니라 구성·정책·워크플로로 처리된다.

## 11. 새 작업 환경용 핵심 요약
AI CREATOR STUDIO는 B2B 중심의 확장형 AI 비주얼 제작 플랫폼이다. 패션에 한정하지 않고 공통 플랫폼(Core)을 먼저 구축한 뒤, 패션·이커머스·뷰티·부동산·식품·여행·광고 등의 산업별 모듈을 추가한다. 공통 핵심 모듈은 Asset Engine, AI Creation Engine, Identity & Brand Engine, Template & Preset Engine, Workflow Engine, Workspace & Collaboration Engine, Commerce & Entitlement Engine의 7개다. 고객은 플랫폼 기본 에셋을 활용하거나 자신의 사진·상품·브랜드 자료를 업로드해 작품을 만든다. AI 공급자 어댑터, API 우선, 기업별 데이터 격리, 워크플로 재사용, 자산 권리·출처 추적을 초기 설계부터 고려한다. 초기는 모듈형 모놀리스와 비동기 작업 큐로 시작하고, 실제 필요가 생길 때 서비스를 분리한다. 마켓플레이스는 사용자가 만든 자산을 명시적 권리 확인 후 거래하는 장기 확장 기능이다.
