# BUILD-00099 — Variant-aware Lookbook Drafts

## Implementation

- Extended `LookbookDraftInput` with `product_variant_ids` (up to 40 unique active variants in the same Workspace).
- Lookbook resolves a selected Variant's active variant-specific image assets. If none are attached, it falls back to the parent Product's active image gallery.
- Resolved images are snapshotted into `lookbook_draft_assets` and protected from deletion while the Lookbook Draft remains active.
- Draft entity references retain both parent `product` and `product_variant` IDs. Parent Product archive and Variant update/archive are blocked while an active Lookbook Draft references them.
- Extended `lookbook_draft_entities` constraint migration to support `product_variant`, preserving existing Project/Character/Product rows.
- Extended `LookbookDraftWorkspace` with a multi-select for active Product Variants and explicit count/asset fallback guidance.
- Product and Variant references may be combined; duplicate resolved image assets are de-duplicated before persistence.
