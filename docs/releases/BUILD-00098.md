# BUILD-00098 — Project ↔ Product Assignment

## Implementation

- Added workspace-scoped Project-to-Product assignment API: `GET/PUT /v1/projects/{project_id}/products`.
- Added `GET /v1/projects/{project_id}/product-events` for retained assignment change history.
- Assignments are replace-set semantics, bounded to 100 active Product IDs. Every Product must be ACTIVE and belong to the Project's Workspace.
- Assignment order is preserved and can be changed; reordering is audited. Repeated identical requests are idempotent and do not add redundant events.
- Removed assignments are soft-closed with `removed_at`; historical assignment rows and append-only change events remain.
- Product archive is blocked while it is assigned to any ACTIVE Project. Archive the Project or remove the Product assignment first. Archived Product rows are hidden from the Project's active product list.
- Added `ProjectProductAssignmentWorkspace` UI for project selection, multi-product assignment, order management and history display.
