# 여유·압력 맵 — S/M/L 비교 (M4 · 레인 2)

`app/ease_map.py` + `scripts/ease_sheet.py` — 같은 몸에 옷 S·M·L을 입혔을 때 **어디가 끼고 어디가 헐렁한지**를 숫자와 색 지도로 본다(순수 파이썬, 모델·네트워크 없음).

## 핵심: 사이즈는 "고정된 옷"이다
`garment_deform`은 옷을 몸에 **맞춰 키우거나 줄여서** 끼는 것을 숨긴다. 여기서는 반대로 **옷은 절대 치수로 고정**하고 몸만 바꾼다. 사이즈 사다리 = **기준 몸(`nominal`, 이 옷의 M이 누구용인지; 기본은 프리셋)의 가슴·허리·엉덩이 −4 / 0 / +4 cm**로 만든 옷(여유 4 cm). 그래서 작은 옷을 큰 몸에 입히면 **끼는 것으로** 나온다. 길이만 몸의 키를 따라간다(폭은 키우지 않음).
## 두 가지 결과
1. **부위 여유**(표준 사이징 논리): 옷 둘레 − 몸 둘레(가슴·허리·엉덩이, 옷 종류별로 해당 부위만). 분류(**제안 경계**): `tight` <0 cm(안 잠김) · `fitted` 0~4 · `regular` 4~10 · `loose` >10.
2. **꼭짓점 간격**(압박 지도): 옷의 꼭짓점마다 그 높이의 **몸 단면에서 얼마나 떨어져 있는가**(cm, **음수 = 몸 안쪽 = 압박**) → 색(빨강 끼임 → 초록 맞음 → 파랑 헐렁). S·M·L을 한 장에 나란히(`render_sheet`), 옷을 몸 **위에 겹쳐**(엑스레이) 그려서 몸 안쪽에 들어간 끼는 옷도 보이게 했고 색은 조명 없이 범례와 정확히 일치시킴.
**추천** = 모든 부위 여유가 `MIN_EASE_CM`(제안 2 cm) 이상이고 몸 안쪽 꼭짓점이 `MAX_PRESSURE_SHARE`(제안 2%) 이하인 **가장 작은 사이즈**, 없으면 `None`("사이즈 사이이거나 최대 사이즈보다 큼"). 두 한계도 **제안값**.

## 확인한 동작 (기준 몸 170/92/76/98 cm, 여성 상의, `tests/test_ease_map.py`)
| 몸 | 추천 | 비고 |
|---|---|---|
| 작은 몸 155/80/64/88 | **S** | S 여유 가슴 +12 |
| 기준 몸 | **M** | S는 여유 0 cm·꼭짓점 33%가 몸 안 → 탈락 |
| 사이 몸 170/96/80/102 | **L** | M은 여유 0 → "여유 부족", S는 끼임(가슴 −4) |
| 큰 몸 185/108/92/112 | **없음** | 모든 사이즈에서 가슴·허리 `tight` |
M의 여유는 모든 종류·성별에서 **정확히 4.0 cm**(S 0, L 8). **재킷은 겉옷이라 +6 cm 더 헐렁하게** 만들어져(`JACKET_EXTRA_EASE_CM`) 기준 몸에서도 S가 이미 약 5.9 cm 여유라 S가 추천된다 — 의도된 구조다.

## 이게 아닌 것 (정직하게)
- **천 시뮬레이션이 아니다**: 힘·늘어짐·주름 없음. **원단 신축(니트는 용서하는 것을 직물은 못 용서함)을 고려하지 않는다** → "tight"는 기하학적 겹침이지 힘이 아니다.
- **몸은 양식화된 마네킹**(`base_models`)이지 사람이 아니고, 옷은 **샘플 튜브**다. 실제 의류의 패턴·사이즈표와는 다르다. 결과는 **사이즈 안내 보조**이며 실제 옷이 실제 사람에게 맞는다는 약속이 아니다.
- 사이즈 간격(4 cm)·여유(4 cm)·분류 경계·추천 한계는 **제안값**(설계 창이 정함). 사이즈 수는 S/M/L 3개뿐.
- 팔·다리 부분(바지 다리, 재킷 소매)의 간격은 같은 방식으로 재지만 **부위 여유 표에는 포함하지 않는다**(가슴·허리·엉덩이만).
- API·화면 연결은 **미착수**(모듈·스크립트·시험까지).
