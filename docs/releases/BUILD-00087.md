## Behavior

`POST /v1/generation-jobs/{job_id}/cancel` is available to workspace owner/admin/editor. It cancels only a queued Job whose latest submission outbox record remains pending. Job and Execution become `failed` with `error_code=JOB_CANCELLED`, the pending outbox record becomes processed, and a cancellation Event is appended in one SQLite transaction. If dispatch is already claimed or the Job is no longer queued, the API returns 409.

This is not remote cancellation of an already submitted Provider request. A dedicated `cancelled` status is deferred until a schema migration and versioned API contract are prepared.
