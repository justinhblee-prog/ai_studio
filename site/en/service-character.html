Character Studio

Create brand models and characters and keep them consistent across scenes.

The aim is to reduce a model’s face changing from shot to shot. Picking library models by attributes (skin tone, hair, body type, age range, regional style) is the first step.

  1. Pick by attributes (library comes first)
  2. Save as a brand-only model
  3. Reuse the same model across scenes and outfits

In detail

When you use it

Uses

  • A brand-only model, the same person in every shot
  • Set skin, hair, face, mood, background and lighting by attributes
  • Pick from several candidates and save

What goes in and out

In: Attributes, instruction text, optional reference photos

Out: Candidate images, brand model with attributes, scene images

How it differs

Built as a tool

Category rail, preview and spec sheet instead of long lists.

Ask in plain words

Say "curly hair, golden hour" and the options are picked.

Saved values persist

All chosen values are saved with the brand model.

Where it really stands

  • Works Attribute selection, preview, candidates, saving
  • In development Same-person consistency and real face/hair rendering follow the AI provider connection
