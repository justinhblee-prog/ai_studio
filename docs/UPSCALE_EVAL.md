# 업스케일 (E-09d · 레인 3)

`app/upscale.py` — 사진 단계(`photo-steps`)의 새 연산 `upscale`(`factor_pct` 100~400, 기본 200 = 가로세로 2배 / `sharpen_pct` 0~100, 기본 30). **고전 보간(Pillow Lanczos) + 약한 언샤프 마스크**. AI 모델·네트워크·새 의존성 없음, 결과는 기존 사진 단계처럼 새 자산(출처 기록 `mode: local`, `is_ai_generated: false`).

## 이게 아닌 것 (정직하게)
**없던 디테일을 만들어 내지 않는다.** 흐린 사진은 흐린 채 커질 뿐이다(그건 초해상도 모델 — 승인된 적 없음, 별도 NEED_USER). 확대는 채널 규격(최소 크기)을 맞추거나 인쇄용 여유를 줄 때 쓰는 것이다.

## 후보 비교 (왕복 측정, `upscale.round_trip_table()`)
선명한 합성 그림 5종(가는 세로줄·**7px 체커**·글자 같은 획·원·잡음 섞인 물결)을 박스 필터로 1/배율 축소 → 후보별로 다시 확대 → 원본과 PSNR(dB, 높을수록 원본에 가까움, 완전 일치는 60으로 상한).
| 후보 | 1.5배 | **2배** | 3배 | 4배 |
|---|---|---|---|---|
| nearest | 20.48 | 19.40 | 15.25 | 16.64 |
| bilinear | 20.23 | 19.41 | **15.98** | 17.05 |
| bicubic | 20.60 | 19.97 | 15.95 | 17.45 |
| lanczos | 20.63 | 20.07 | 15.91 | 17.57 |
| bicubic+선명화30 | **20.79** | 20.33 | 15.85 | 17.54 |
| **lanczos+선명화30** | **20.79** | **20.41** | 15.80 | **17.67** |
**선택: lanczos + 선명화 30**(기본값). 2배·4배에서 1위, 1.5배는 bicubic+선명화와 동률. **3배는 bilinear가 근소 1위지만 차이가 0.2 dB 이내이고 축소 크기가 정수로 떨어지지 않아(128→42) 이 측정이 흔들린다** — 그래서 기본값을 배율별로 바꾸지 않았다. 전체적으로 후보 간 차이는 **작다**(2배에서 1위와 최하위가 1 dB 남짓).
**측정 중 고친 결함**: 처음 평가셋의 체커판 칸이 8px(2배 축소 격자와 일치)라 `nearest`가 원본을 그대로 복원(PSNR 99)해 평균을 끌어올려 1위로 나왔다 → 칸을 7px로 바꾸고 완전 일치 값에 상한을 둠.

## 안전장치
- 결과가 **한 변 8192px 또는 4천만 화소**를 넘으면 **할당 전에** `STEP_RESULT_TOO_LARGE`(422)로 거부.
- 투명 PNG: 알파 유지, 리사이즈는 알파 곱셈 상태로 계산해 가장자리가 검게 번지지 않음. 선명화는 투명 영역에서 2~3px 안쪽에만 적용해 **어두운 테두리가 생기지 않음**(시험으로 고정).

## 못 한 것
실제 사진으로의 비교(합성 그림뿐), 사람 눈 평가, 초해상도 모델, 확대 후 노이즈 제거, 화면(UI)·채널 규격 프리셋과의 연결(`photo_presets`는 그대로).
