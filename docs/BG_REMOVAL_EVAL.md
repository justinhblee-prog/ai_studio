# E-09a 배경 제거 후보 비교 (2026-11-17, 레인 3)

**범위**: Pillow만 쓰는 고전 영상 처리 후보 2종 + 둘을 섞은 `auto`. AI 컷아웃 모델(U²-Net, rembg, 유료 API)은 새 의존성·모델 파일·외부 전송이 필요해 **이번에 쓰지 않았고 비교하지 않았다**(NEED_USER: 승인·예산).
**평가셋**: `app/bg_removal.py::evaluation_set()` — 합성 10장(160×160): 흰/회색/약한 그라데이션/강한 그라데이션/잡음 배경 위의 타원·사각·도넛 제품, 그리고 **일부러 어려운 1장(흰 제품·흰 배경)**. 정답 마스크는 도형 그대로. **실제 사진은 한 장도 없다 → 실제 제품 사진의 성능은 미측정.**

## 알려진 한계 (시험으로 고정)
- **닫힌 구멍(도넛 구멍, 손잡이 사이 빈 공간)은 제품으로 남는다** → IoU 0.87. 배경이 테두리에서 이어지지 않으면 못 지운다.
- **제품 색이 배경과 비슷하면 불확실**: 흰 제품·흰 배경은 `gradient`가 0.65. `removal_confidence()`가 "reliable=false + 경고"를 돌려주도록 해 두었다 — **화면은 이 경고를 보여 줘야 한다.**
- **복잡한 배경(사진 속 거리, 잡음)**은 고전 방식으로 안 된다 → 경고만 한다.
- 가장자리는 가우시안 0.8px로 부드럽게 하지만 **머리카락·털 같은 반투명 경계는 못 다룬다**.
