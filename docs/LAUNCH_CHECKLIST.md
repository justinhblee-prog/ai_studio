# 출시 체크리스트 (제한된 B2B 파일럿) — 증거 유무 표

> **초판 2026-11-09, 11/28에 갱신할 것.** 저장소에는 별도의 출시 기준 문서가 없어서 **항목은 이 세션이 구성한 것**이다(법률 항목은 `docs/project-design/imported-reference/AI_CREATOR_STUDIO_integrated_execution_baseline_v0_2.md` 538행의 "출시 전 검토 항목"과 `docs/LAUNCH_STATUS.md`의 요청 큐를 따름).
> 규칙: **증거(머지된 PR의 CI 수치, 시험 이름, 파일)가 없으면 "미완료"**. "부분"은 구현·시험은 있으나 표에 적은 공백이 남은 것. "차단"은 입력·승인·명세가 없어 시작하지 못한 것. 증거의 CI 수치는 해당 PR 머지 시점의 GitHub Actions 로그 그대로다.
