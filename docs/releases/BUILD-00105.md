# BUILD-00105 — Deterministic Local Photo Processing (ENHANCE / LIGHTING)

## Implementation

- Added a bounded, explicitly non-AI local Photo processor using Pillow `pillow-local-1.0`.
- `ENHANCE` applies guarded autocontrast (only when channel dynamic range is meaningful), mild color and sharpness adjustments. `LIGHTING` applies bounded brightness/contrast adjustments. Input geometry/dimensions are retained; metadata is not copied.
- `BACKGROUND`, `RETOUCH`, and `COMPOSE` fail closed with an AI-engine-required response. Local execution also rejects multiple outputs, masks, reference images, style notes and natural-language prompts rather than silently ignoring them.
- Added `POST /v1/photo-drafts/{draft_id}/process-local?workspace_id=...` with required `Idempotency-Key` (8..128 chars), `GET .../runs`, and paginated `GET .../runs/{run_id}/events`.
- Added durable `photo_processing_runs` and append-only `photo_processing_events`. Idempotency conflicts, concurrent active runs, failed-run retry, and expired 30-minute lease reclaim are handled. Event UPDATE/DELETE is blocked by SQLite triggers.
- Each successful run creates a new private derived Image Asset with immutable AssetVersion v1, SHA-256 checksum, `derived_from` relation and `asset.photo_processed` provenance. Asset IDs are deterministic per run so a retry can reuse a committed asset after a crash before run acknowledgement.
- Derived Photo outputs are protected from ordinary Asset deletion pending a future retention workflow.
- `PhotoDraftWorkspace` now exposes local processing only for compatible ENHANCE/LIGHTING drafts and shows output Asset/Version and semantic preservation limits.
- Explicit truth boundary: `is_ai_generated=false`, `provider_dispatched=false`, `credit_charged=false`. Spatial geometry preservation is measured by unchanged dimensions; identity/text/logo semantic preservation is **not verified** and outputs require human review.

## Boundaries

- This is deterministic image adjustment, **not generative AI** and not a substitute for Photo Engine background segmentation, semantic retouch, compositing or generation.
- No Provider call, credit charge, public URL, commercial-use clearance or publication permission is created.
- SQLite/local filesystem only. The deterministic asset key supports retry recovery, but filesystem and SQLite are not one atomic transaction; a process crash may leave a temporary/orphan file requiring maintenance.
- PostgreSQL, multi-host storage/locking and production deployment remain unverified. G0-G5 remain unpassed.
