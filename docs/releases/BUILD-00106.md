# BUILD-00106 — Photo Output Review / Approval / Internal Manifest Export

## Implementation

- Added `photo_output_review_events` and `photo_output_export_events` to the Asset/Photo SQLite database. UPDATE/DELETE is blocked by database triggers.
- Added workspace-scoped `GET /v1/photo-drafts/{draft_id}/runs/{run_id}/review`.
- Added owner/admin-only `POST .../review/approve`, `/review/request-changes`, and `/review/reject`. Change requests and rejections require a non-empty comment. `changes_requested` may be reviewed again; `approved` and `rejected` are terminal.
- Every review event snapshots Asset ID, immutable AssetVersion ID, `asset.photo_processed` Provenance ID and SHA-256 checksum.
- Review and export verify the exact immutable AssetVersion file (storage key path containment, recorded size and SHA-256). They do not bind approval to the mutable current-version pointer; uploading a later AssetVersion does not invalidate approval of the reviewed v1.
- Added owner/admin/editor `POST .../export-manifest`. It requires the latest decision to be `approved` and the approved snapshot to match the immutable output version. It creates a canonical SHA-256 metadata manifest and append-only export audit event.
- Manifest is metadata only, includes no binary file or public URL, and explicitly sets `is_ai_generated=false`, `publication_authorized=false`, `commercial_rights_verified=false`, `binary_files_included=false`.
- `PhotoDraftWorkspace` now displays review status, approve/request-changes/reject controls, and gated internal manifest export.

## Boundaries

- Approval is internal visual/workflow approval only; it is not copyright, likeness/consent, brand, legal, publication or commercial-use clearance.
- Export is an internal metadata manifest, not a ZIP/binary download or public distribution.
- The underlying ENHANCE/LIGHTING processor is deterministic Pillow processing, not generative AI. BACKGROUND/RETOUCH/COMPOSE remain unavailable without an actual AI Photo Engine.
- SQLite/local filesystem only; PostgreSQL/multi-host/production remain unverified. G0-G5 remain unpassed.
