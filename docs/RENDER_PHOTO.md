# 사진 느낌 렌더 (E-03) — `app/render3d_photo.py`

순수 파이썬 + Pillow(GPU·모델·새 의존성 없음). 기존 `render3d_soft`(빠른 모형)는 그대로 두고, 같은 장면을 **조금 더 사진처럼** 그리는 별도 렌더러다. 비교 PNG: `python ai_creator_studio_backend_starter/scripts/render_photo_compare.py out.png`(위: 이전 `render3d_soft`, 아래: E-03, 같은 장면·크기·각도 4개).

## 더한 것 (각각 끌 수 있음: `ao`, `floor`, `ss`)
- **3점 조명**: 따뜻한 키 + 차가운 필 + 뒤 림, 반구 환경광. 선형 빛에서 계산하고 감마 2.2로 인코딩.
- **재질 2종**: `skin`(감싸는 확산광, 빛이 돌아나가는 가장자리의 옅은 붉은 기운, 약한 하이라이트), `cloth`(거칠게, 스치는 각도의 부드러운 광택, 하이라이트 없음).
- **화면 공간 AO 근사**(깊이 버퍼 8방향 표본): 팔 안쪽·옷 가장자리 같은 틈이 어두워짐.
- **바닥 그림자**: 키 조명 방향으로 투영한 부드러운 그림자 + 발 밑 접촉 그림자, 배경으로 서서히 사라짐.
- **가장자리 안티앨리어싱**: 2×2 슈퍼샘플링.

## 한계 (정직하게)
- **사진 같지는 않다.** 레이트레이싱·자기 그림자(몸이 옷에 드리우는 그림자)·텍스처·피부 속 산란·원근 카메라가 없다. 마네킹이 한결 덜 납작해 보이는 정도다(비교 PNG로 판단할 것: 개선은 있으나 크지 않다).
- 몸·옷 메시의 면 단위 음영(각진 느낌)은 메시 해상도 때문에 그대로다.
- 느리다: 270×480 한 장에 약 1.7 초(모형은 0.3 초, 이 PC). **서버 작업 경로는 계속 `render3d_soft`를 쓰며 이 렌더러는 연결하지 않았다**(스틸·비교용). 연결 여부는 설계 창 결정.
- AO 반경·그림자 세기·조명 값은 눈으로 맞춘 **제안값**이다. 8 GB급 PC 시간은 미측정(위 시간은 개발 PC).
- 시험(`tests/test_render3d_photo.py`)은 측정 가능한 성질만 본다: 결정성, 바닥 그림자 존재, 안티앨리어싱, AO가 어둡게 함, 인수 거부.
