# BUILD-00094 — Photo / Lookbook Draft Pagination

## Implementation

- Photo Draft and Lookbook Draft list APIs now support `limit` 1..100 and `offset` >=0.
- List responses include `items`, `total`, `limit`, and `offset`; active/archived filtering is preserved.
- Photo Draft and Lookbook Draft append-only event-history APIs now support `limit` 1..500 and `offset`, with total event counts.
- Companion React Photo/Lookbook preparation UIs request up to 100 active drafts by default.
